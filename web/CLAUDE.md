# Web — знания области

Термины — `CONTEXT.md`. Общий домен — `../backend/CONTEXT.md`.

React 18 + TypeScript + Vite, Plotly.js. Запуск: `cd web && npm run dev` (порт 5173, `/api` проксируется на 8000).

Обязательное ограничение: дашборд адаптивный и touch-friendly с первого дня — его переиспользует iOS-клиент ([ADR-0005](../docs/adr/0005-ios-as-separate-client.md)).

## Визуальный язык

Весь цвет — в `src/theme.ts`, единственный источник. Палитра прогнана валидатором в обеих темах: соседние пары расходятся по CVD (худшая 9,1 светлая / 8,4 тёмная), нормальное зрение 19,6 / 19,3.

**Цвет закреплён за сущностью, а не за местом в списке.** `METRIC_SLOT` жёстко задаёт: **План — синий слот 1, Факт — оранжевый слот 2**, всегда и на всех графиках. Переставить серии местами или отфильтровать часть данных не должно перекрасить остальные — иначе на четырёх графиках дашборда один и тот же план окажется разного цвета.

**Таблица с данными — не удобство, а требование доступности.** В светлой теме три слота палитры (аква, жёлтый, магента) не дотягивают до контраста 3:1, и правило требует страховочного канала: значения, читаемые текстом. `DataTable` и есть страховка — убирать её нельзя.

**Тёмная тема выбрана, а не получена переворотом светлой.** Свои шаги под тёмную поверхность `#1a1a19`. Токены в `styles.css` объявлены трижды: светлые на чистом `:root`, тёмные под `prefers-color-scheme` с защитой `:not([data-theme="light"])` и под `:root[data-theme="dark"]` — чтобы явный выбор побеждал в обе стороны. Ни один цвет не живёт только внутри media-блока.

**Одна ось Y, никогда две.** План и факт в одних рублях. Метрики разных единиц — это разные графики, а не вторая шкала.

**Легенда есть при двух и более сериях и отсутствует при одной** — заголовок её уже называет.

Статусные цвета (зелёный/красный для выполнения плана) зарезервированы и никогда не достаются серии. Идут с иконкой и подписью, цвет в одиночку смысл не несёт.

## Паттерны

**Все подписи русские и собираются на сервере.** Сервер отдаёт `label` для каждой колонки и серии; клиент никогда не строит подпись из имени поля. Числа форматирует `src/format.ts`: неразрывные пробелы в разрядах, запятая как десятичный разделитель, «млн ₽» / «млрд ₽», месяцы как `сен 2026`, кварталы как `III кв. 2026`.

**Даты из базы приходят первым днём периода** (`2026-09-01` для сентября). Показывать сам период, не дату — `periodLabel`.

**Тип графика выбирает сервер**, клиент его только рисует. Правила в `backend/app/charting.py`.

## Gotchas

- **Бандл 4,8 МБ** из-за `plotly.js-dist-min`. Для локального демо терпимо; если понадобится — грузить Plotly динамическим импортом при первом графике.
- **`plotly.js-dist-min` без типов**, объявление в `src/plotly.d.ts` — только те методы, что используются.
- **Plotly нужно явно ресайзить**: на каждом графике висит `ResizeObserver` с `Plotly.Plots.resize`, иначе при смене ширины контейнера график не перестраивается.
- **Тёмная тема перерисовывает график целиком** — цвета уходят в `layout`, не в CSS. Хук `useMode` слушает `prefers-color-scheme` и пересобирает фигуру.
