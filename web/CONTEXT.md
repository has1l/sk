# Web

Веб-клиент: лента чата, рендер дашборда на Plotly, интерактив поверх уже выгруженной плоской таблицы. Бизнес-логики нет — только отображение и локальный пересчёт. Доменные термины (план, факт, разрез, метрика, зерно) определены в `../backend/CONTEXT.md`; здесь только то, что специфично для клиента.

## Language

**Лента**:
Хронологический поток реплик диалога. Дашборд встраивается в ленту как элемент, а не открывается отдельным экраном.
_Avoid_: чат, история, тред, фид

**Состояние фильтров**:
Текущий выбор во всех фильтрах и переключателях дашборда. Живёт на клиенте, применяется ко всем графикам и KPI одновременно, входит в сохраняемый дашборд.
_Avoid_: selection, настройки, параметры

**Срез таблицы**:
Плоская таблица после применения состояния фильтров. То, из чего в данный момент рисуются графики и считаются KPI.
_Avoid_: отфильтрованные данные, subset, view

**Спецификация графика**:
Описание одного графика из конфига дашборда: тип, какие колонки на какие оси, сортировка, серии. Данных не содержит — читается поверх среза таблицы.
_Avoid_: настройки графика, chart config, трейс

**Визуальный язык**:
Общий для всех графиков набор цветов, шрифтов, форматов чисел и подписей. Обязателен: кейс требует, чтобы дашборд выглядел как одно целое.
_Avoid_: тема, стиль, дизайн-система
