# Backend

Сервер: понимает запрос на русском, достаёт данные, держит сессию анализа, считает вычисления, собирает конфиг дашборда, хранит сохранённые дашборды. Домен, описанный здесь, общий для всего проекта — клиенты используют эти же термины.

## Language

**Сессия анализа**:
Состояние одного аналитического диалога: спецификация выборки, плоская таблица, стек вычислений и конфиг дашборда вместе. Единица, которую меняют реплики пользователя и которую сериализуют при сохранении.
_Avoid_: контекст, тред, воркспейс

**Спецификация выборки**:
Структурное описание того, какие данные нужны: разрезы, метрика, период, зерно, фильтры. Результат разбора запроса на естественном языке; из неё наш код собирает SQL.
_Avoid_: query plan, интент, запрос

**Плоская таблица**:
Одна денормализованная таблица на общем зерне плана и факта, из которой строятся все графики и KPI дашборда. Единственный источник чисел для клиента.
_Avoid_: датафрейм, выгрузка, датасет, витрина

**Зерно**:
Набор полей, определяющих одну строку плоской таблицы. Базовое зерно проекта — `месяц × точка × продукт`; мельче спускаться нельзя, потому что плана там нет.
_Avoid_: гранулярность, granularity, уровень детализации

**Разрез**:
Измерение, по которому группируются числа: регион, торговая точка, продукт, категория, клиент, сегмент, период.
_Avoid_: измерение, dimension, группировка, ось

**Метрика**:
Числовая величина, которую показываем: объём продаж, количество, сумма скидки, процент выполнения плана.
_Avoid_: показатель, мера, measure, KPI

**План**:
Целевая сумма продаж на `месяц × точка × продукт` из `sales_plan`. Клиента и договора не содержит.
_Avoid_: таргет, бюджет, норматив

**Факт**:
Фактическая сумма продаж из `sales`, агрегированная до зерна плоской таблицы.
_Avoid_: actual, реализация, выручка

**Отклонение**:
Разница «факт минус план». Отрицательное — отставание. Бывает абсолютным в рублях и относительным в процентах от плана.
_Avoid_: дельта, разрыв, gap, variance

**Выполнение плана**:
Отношение факта к плану в процентах. 100% — план выполнен ровно.
_Avoid_: достижение, performance, execution rate

**Шаг вычисления**:
Одна именованная операция, добавляющая колонку в плоскую таблицу: тип операции, параметры, зависимости. Не код — структура.
_Avoid_: формула, трансформация, calculated field

**Стек вычислений**:
Упорядоченный список шагов вычисления. Таблица пересобирается его прогоном, а не мутируется — отсюда возможность отката и правки формулы.
_Avoid_: пайплайн, цепочка, история расчётов

**Конфиг дашборда**:
Описание того, как читать плоскую таблицу: KPI-карточки, фильтры, переключатели, спецификации графиков. Чисел не содержит.
_Avoid_: макет, layout, схема дашборда

**KPI-карточка**:
Одна итоговая цифра в шапке дашборда с подписью и цветовой индикацией. Пересчитывается вместе со всем дашбордом при изменении состояния просмотра.
_Avoid_: плитка, тайл, виджет, метрика

**Намерение**:
Что пользователь хочет сделать с сессией: новый вопрос, правка выборки, фильтр, переключатель, вычисление, откат, сохранение. Закрытый список; распознаёт модель, исполняет код.
_Avoid_: интент, команда, action

**Состояние просмотра**:
Всё, что пользователь крутит руками, не меняя выборку: основной разрез, зерно периода, метрика переключателя, вид, фильтры, сортировка. Входит в сохраняемый дашборд.
_Avoid_: настройки, selection, параметры вида

**Панель**:
Один график дашборда вместе со своей группировкой таблицы и подписями. Четыре панели дашборда — четыре разные группировки одной таблицы сессии.
_Avoid_: виджет, карточка, чарт, блок

**Горизонт факта**:
Последний месяц, в котором есть продажи. От него считаются относительные периоды, и по нему обрезается план — иначе выполнение выглядит заниженным.
_Avoid_: дата среза, последняя дата, cutoff

**Уточняющий вопрос**:
Ответ сервера вместо спецификации выборки, когда запроса недостаточно, чтобы однозначно понять период, разрез или метрику.
_Avoid_: clarification, переспрос, disambiguation
